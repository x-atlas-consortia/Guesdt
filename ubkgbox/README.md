# Guesdt application
## Graphing UMLS Enables Search In Dynamic Trees

The files in this directory are for a deployment of 
Guesdt as the application served by the **ubkg-guesdt** 
service of a **UBKGBox** multi-container application.

The **UBKGBox** front end acts as a reverse proxy for 
Guesdt, both for authentication and UBKG instance selection.
Content from the index.html page of the standalone version of Guesdt
is now in the static **userguide.html**.
